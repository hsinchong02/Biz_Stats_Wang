A QUICK START

From data to understanding.

  1. Enter or paste data into the spreadsheet, or import CSV or Excel.
  2. Select an analysis, then drag across the cells to fill its data range. Mark the first selected row as a label if appropriate.
  3. Run the analysis and download the result as an Excel or Word report.

Use Data settings & grid size to set up to 110,000 rows. The grid supports drag selection, copy, cut, paste, Delete, undo and redo. At most 250,000 cells can be populated.
