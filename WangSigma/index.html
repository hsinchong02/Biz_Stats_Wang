A QUICK START

From data to understanding.

  1. Enter data. Paste cells into the grid, import CSV/Excel, or load an example. Mark headers as needed. Numeric-text conversion is enabled by default and can be turned off for categorical codes.
  2. Choose an analysis. Browse categories or search. Set data ranges with Excel-style addresses; use “Use selection” to copy the current grid selection.
  3. Check the method. Read assumptions, choose your hypothesis or parameters, then run the analysis.
  4. Explore results. Review tables, charts, exclusions, and interpretation. Past results are saved snapshots under the collapsed Past results section; only the current result is expanded.
  5. Keep your work. Download genuine Excel/Word reports or save a project file to reopen later.

Calculations run locally. No data is uploaded. A saved project contains your data and results; keep it where you want to store them.

For discrete probability distributions, select X and P(X = x) columns. Their probabilities must sum to 1. The value/probability table appears beside the bar chart.

Not a full Excel formula engine. Imported formulas use saved values. For a local developer preview, see README.md; students use the hosted URL.
